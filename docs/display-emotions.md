# Display and emotions

## Display daemon `st7789_server`

| Item | Value |
|---|---|
| Source | `st7789/` (libdriver/st7789), build in `st7789/project/riderpi` |
| Panel | 2", ST7789, 320×240 |
| Input | FIFO `/tmp/lcd0`, raw RGB565, 153 600 bytes per frame |
| Start | `deploy/rc.local` (or `st7789_display.service` via `make install` — not both) |
| Permissions | `/tmp/lcd0` group `video`, g+w |
| Throughput | > 40 fps (measured) |

```
make -C st7789/project/riderpi && sudo cp st7789/project/riderpi/st7789_server /usr/bin/
```

## xgonav overlay on the LCD (`xgonav/lcd.py`)

| Item | Value |
|---|---|
| Enabled | `--robot proc` and `output.lcd_fifo` ≠ `""` (`--no-lcd` disables) |
| Rate | `output.lcd_fps` = 15 (no measurable main-loop cost on CM4) |
| Pauses | while an emotion is playing (`/tmp/lcd0.owner` non-empty, < 10 s old) |

## Emotion player (`tools/emotion.sh`)

```
tools/emotion.sh build SRC DST      # SRC/<Name>/<Name><n>.png -> DST/<Name>/0001.raw ... (numeric order)
tools/emotion.sh play DIR [FPS]     # plays DIR/*.raw once, default 25 fps
```

| Item | Value |
|---|---|
| Frames | `/opt/xgonav/emotions`, generated by `tools/eyes.py` in `deploy/install.sh` |
| Fallback | no `.raw` files → decodes PNGs with ffmpeg |
| CPU (RiderPi) | 55 frames ~0.18 s (old ffmpeg path: 1.04 s for 24 frames) |
| Ownership | newest player writes its PID to `/tmp/lcd0.owner`; older players exit before next frame (works across users) |
| `/tmp/lcd0.owner` | created by `rc.local`: root, group `video`, 0664 (`fs.protected_regular`) |

## Eye animations (`tools/eyes.py`)

Stylized eyes only, one color on black (antialiased), same output format as `emotion.sh build`.

```
python tools/eyes.py OUTDIR [--color R,G,B] [--only NAME]... [--png] [--preview DIR]
python tools/eyes.py --list
python tools/eyes.py --gaze DIR      # eye atlas for mode pet: 11 gaze positions (10 steps) x 5 lid positions, 55 frames, 8.4 MB
```

| Item | Value |
|---|---|
| Output | `OUTDIR/<Name>/0001.raw ...`, 320×240 RGB565 LE, 153 600 bytes (same as `emotion.sh build`) |
| Length | 55–100 frames at 25 fps (2.2–4.0 s), 915 frames / 139 MB in total |
| Loop | first and last frame = neutral eyes (except `sleep`: ends closed) |
| Color | default turquoise `0,225,210` |
| `--png` | also writes `<Name><n>.png` |
| `--preview DIR` | contact sheet `<Name>.png` and `<Name>.mp4` per emotion |
| Runtime | ~7 s on a PC for all 13; needs only numpy + OpenCV |
| Install | `deploy/install.sh` → `/opt/xgonav/emotions`; the web UI lists this directory |

| Emotion | Eyes |
|---|---|
| `Angry` | lids slanted down toward the center, trembling, two pulses |
| `cute` | large round eyes without pupils, smiling lower edge, gentle bob, head tilt, short `^ ^` squint |
| `doubt` | one eye raised, other squinted, glance right then left |
| `embarrassed` | darting glances left/right, then trembling `> <` |
| `grievance` | round pleading eyes looking up, sad lids, quivering lower lid, tear |
| `hate` | eye roll upward, then narrowed frowning slits, side glance |
| `laugh` | `^ ^` arcs bouncing |
| `like` | heart eyes beating |
| `sad` | lids drooping outward, eyes sink, slow blink |
| `shy` | smaller half-closed eyes looking down/aside, one glance back |
| `sleep` | lids get heavy, two jerks awake, closed `‿ ‿`, breathing |
| `surprised` | eyes pop to large circles (overshoot), double blink |
| `vertigo` | rotating spirals circling in opposite phase |

## Automatic emotions

| Emotion | Trigger | Source |
|---|---|---|
| `cute` | boot | `rc.local` |
| `sleep` | shutdown from web UI (before `poweroff`, timeout 10 s) | `api.php` |

Sleep mode (web **Ruhe**): `st7789_server` gets SIGUSR1 (DISPOFF + SLPIN, frames discarded), SIGUSR2 wakes it; xgonav writes nothing and plays no emotions meanwhile.
| `surprised` | person appears after ≥ `gap_s` (5 s) without person | `xgonav/emotion.py` |
| `doubt` | mode `follow`, no person for `lost_s` (2 s); once per loss | `xgonav/emotion.py` |
| `embarrassed` | other modes, no person for `lost_s`; once per loss | `xgonav/emotion.py` |
| `shy` | battery ≤ `battery_low` (20 %), repeated every 300 s | `xgonav/emotion.py` |

- xgonav emotions only with `--robot proc` and `emotion.enabled`.

## Sounds

| Item | Value |
|---|---|
| Found | `freude.wav` (3 rising chirps, 0.5 s) when a person appears |
| Lost | `trauer.wav` (2 falling "wah", 1.1 s) after `lost_s` (2 s) without person |
| Independent of | display (plays even while an emotion runs), mode |
| Files | `tools/sounds.py DIR` (numpy only); `deploy/install.sh` → `/opt/xgonav/sounds` |
| Playback | `aplay` (ALSA default, `emotion.sound_device`), WM8960 speaker; volume `amixer -c 0 sset Speaker 82%` |
| Off | `[emotion] sound = false` |
- Pipeline stopped → person unknown → battery trigger only.
- Emotion already playing → trigger waits (not interrupted).
- Manual: web UI → Extras → Emotionen (`POST api.php?a=emotion&name=..`).

## Mode `pet` (`xgonav/pet.py`)

Started by hand (web UI „Haustier“, `--mode pet`). Not run on the Rider yet, see [limitations.md](limitations.md).

| Trigger | Reaction |
|---|---|
| person > 3 m | notices, chirp |
| person 1.5–3 m | turns toward, tilts head (roll), `doubt` |
| person < 1.5 m | `cute`, trill, wiggle |
| person < ~0.5 m | `shy`, ducks |
| box top free and < 1.9 m (kneeling, sitting, child) | `like` |
| person approaching > ~1 m/s within 1.6 m | `surprised`, squeak, duck, optional jerk back |
| person gone < 3 s and back | `laugh`, giggle |
| person gone > 3 s | looks after them, then `sad` |
| wheels move without a drive command | `embarrassed`, „hey“ |
| nobody for 60 s / 180 s / 600 s | sighs and looks around / dozes, detector 1 Hz / sets down, `idle` |
| cat | turns toward, `like`, coo; optional creep up to 0.8 m |
| dog within 2 m (priority over all) | keeps looking, `grievance`, whimper, duck, optional jerk back |
| dog < 0.5 m or hard scare (with `faint`) | faint, see below |

Eyes follow the bearing of the target, gliding one position per control step, and blink through all lid positions in 0.4 s (atlas, neutral eye style without pupils, replaces the overlay on the LCD; written only when changed, checked at ~33 Hz). Priority: dog, cat, person. Trust (0..1) shifts thresholds; repeated scares weaken (habituation).

### Faint

`vertigo`, set down, eyes shut `nap_s` (10 s) → eyes open slowly over `eyes_open_s` (3 s) while looking left and right → anyone in view: eyes shut again, wait → nobody in view for `clear_s` (2.5 s): wake-up sound `standup_warn_s` (1.5 s) → stand up (253) → `settle_s` (6 s) without gestures.

It stands up by itself only if all hold:

| Condition | Otherwise |
|---|---|
| set down by itself (external set-down, fall, started lying) | stays down |
| still in mode `pet` (`POST /stop`, any mode change, web action 254) | stand-up cancelled |
| IMU within `nap_tilt_deg` (5°) and wheels within `nap_moved_m` (1 cm) of the resting pose; `state` unchanged and not 0/250/251/252; all three known | stays down |
| no detection in the image, any class among person/cat/dog, any confidence | waits; gives up after `nap_max_s` (60 s) |
| battery known and > `battery_low` | as above |
| fewer than `faint_max` (3) faints in 10 min | scare instead of faint |

One attempt only.
